# Proxi

Proxi is a trusted marketplace that connects customers with verified local professionals such as plumbers, electricians, painters, cleaners, carpenters, AC technicians and other artisans.

The objective of the waitlist is to validate demand before building the MVP.

Target users:

• Customers looking for trusted professionals.
• Skilled professionals looking for more jobs.

Brand values

• Trust
• Simplicity
• Professionalism
• Accessibility
• Modern Technology
